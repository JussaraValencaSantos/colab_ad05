## 📌 Sobre o repositório

Este repositório reúne atividades práticas desenvolvidas durante minha formação em **Análise de Dados pela Generation Brasil — Turma AD05**.

O objetivo é registrar minha evolução nos estudos de programação Python, com foco na compreensão de APIs, integração com serviços externos e utilização de dados em aplicações.

As atividades são desenvolvidas no ambiente Google Colab, permitindo praticar conceitos apresentados durante as aulas.

## 🎯 Objetivos de aprendizagem

- Desenvolver habilidades de programação em Python.
- Compreender o funcionamento de APIs.
- Conhecer os principais métodos de requisição HTTP.
- Praticar a interpretação de respostas de serviços externos.
- Aprimorar a organização e a documentação de códigos.
